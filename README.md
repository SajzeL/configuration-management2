# Инструмент визуализации графа зависимостей pip-пакетов

## 1. Общее описание
Данное CLI-приложение предназначено для автоматического анализа и визуализации графа зависимостей пакетов экосистемы Python (pip) с учётом транзитивности. Инструмент строит граф на основе данных из удаленного или локального тестового репозитория и генерирует графическое представление.

## 2. Описание всех функций и настроек
Управление приложением осуществляется через опции командной строки:
* `--package` — Имя анализируемого Python-пакета (Обязательный параметр).
* `--repo` — URL-адрес PyPI-репозитория или путь к локальному тестовому файлу (Обязательный параметр).
* `--version` — Конкретная версия пакета для анализа (Обязательный параметр).
* `--max-depth` — Максимальная глубина рекурсивного обхода зависимостей (Обязательный параметр, целое число >= 0).
* `--test-mode` — Режим работы: `true` для работы с тестовым файлом описания графа, `false` для реального PyPI (Обязательный параметр).
* `--filter` — Подстрока. Пакеты, содержащие эту подстроку в имени, будут исключены из анализа.

### Обработка ошибок и валидация:
Приложение осуществляет строгую проверку входных параметров перед началом работы. Программа завершится с кодом ошибки `1` и выводом понятного сообщения на русском языке в случаях:
* Пропуска любого из обязательных параметров.
* Дублирования флагов конфигурации при запуске.
* Передачи некорректного типа данных (например, строки вместо числа в параметр `--max-depth`).
* Передачи отрицательного числа в качестве максимальной глубины обхода.

## 3. Описание команд для сборки проекта и запуска тестов
Для работы приложения необходима установленная среда выполнения **Java (JDK) версии 17 или выше**.

* **Сборка проекта и запуск:**
  Приложение поставляется со встроенным автоматическим скриптом запуска, который сам соберёт автономный "толстый" JAR-архив (включающий стандартную библиотеку Kotlin) при первом обращении:
  ```bash
  .\run.bat [параметры_запуска]
  ```

* **Запуск тестов:**
  ```bash
  .\gradlew.bat test
  ```

## 4. Примеры использования

### Пример 1. Валидация аргументов (Пропуск обязательного параметра):
```bash
.\run.bat --package Flask --repo https://pypi.org --version 3.0.0 --max-depth 2
```
*Вывод в консоль:* `Ошибка конфигурации: Параметр --test-mode является обязательным`

### Пример 2. Запуск Этапа 2 (Получение чистых прямых зависимостей пакета Flask v3.0.0):
```bash
.\run.bat --package Flask --repo https://pypi.org --version 3.0.0 --max-depth 2 --test-mode false --filter test
```

*Пример успешного вывода на экран:*
```text
Werkzeug
Jinja2
itsdangerous
click
blinker
importlib-metadata

python-dotenv
```
